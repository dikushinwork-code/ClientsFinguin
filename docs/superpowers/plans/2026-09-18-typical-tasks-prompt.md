# Промпт для сессии реализации

Скопируйте текст ниже в новую сессию Claude Code, открытую в корне проекта.

---

Реализуй блок «Типовые задачи» в дорожной карте по готовой спецификации и плану.

Документы:
- Спецификация: `docs/superpowers/specs/2026-09-18-typical-tasks-design.md`
- План реализации по задачам: `docs/superpowers/plans/2026-09-18-typical-tasks.md`
- Утверждённый кликабельный макет: https://claude.ai/artifact/8HWtLxKPjK7XLQaYpNJDcw — при сомнениях в разметке или поведении сверяйся с ним, он главнее словесных описаний.
- Справочник шаблонов: `docs/typical-tasks.md` — источник данных, содержимое не менять.

Как работать:
1. Сначала прочитай спецификацию и план целиком, затем `AGENTS.md` и нужные разделы `node_modules/next/dist/docs/` — версия Next.js в проекте отличается от привычной.
2. Создай ветку `feature/typical-tasks` от `main` и работай в ней.
3. Выполняй план строго по задачам через навык `superpowers:subagent-driven-development` (или `superpowers:executing-plans`, если субагенты недоступны): каждая задача — тесты, реализация, `pnpm test && pnpm lint && pnpm build`, отдельный коммит с русским сообщением из плана.
4. Ручные проверки из плана выполняй в браузере через `pnpm dev`; если что-то расходится с макетом, исправляй код, а не ожидания.
5. Не добавляй в интерфейс пояснений, подсказок и упоминаний файлов сверх того, что есть в макете: интерфейсом пользуются финансовые директора, происхождение шаблонов — внутренняя информация.
6. Если план противоречит коду проекта (номера строк сместились, сигнатура отличается), ориентируйся на смысл задачи и текущий код; если противоречие существенное — остановись и спроси.
7. В конце: все задачи плана отмечены, тесты/линтер/сборка зелёные, сквозной сценарий из Task 10 пройден. Покажи `git log --oneline main..HEAD` и краткий отчёт, что сделано и что осталось. Ветку в `main` не сливай без моего подтверждения.
